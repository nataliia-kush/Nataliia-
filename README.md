# Nataliia Kushnir — website

A responsive, custom-designed static portfolio site for GitHub Pages. It uses Nataliia’s supplied photographs, original illustrations and one short process video. The illustrations have not been edited. No third-party portfolio or stock photographs are used.

## Preview

Open `index.html` in a browser. No build step or paid website builder is required. The hero video may not autoplay in every local preview; browsers commonly restrict autoplay, while the site is served over HTTPS.

## Publish with GitHub Pages

1. Create or open the GitHub repository for this website and upload the contents of this folder to its root. Keep `index.html`, `styles.css`, `script.js`, `CNAME` and `assets/` together.
2. In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
3. When GitHub Pages is ready, set the custom domain to `nataliiakushnir.com` in the same Pages settings. The included `CNAME` file already contains this domain.
4. At Namecheap, open **Domain List → Manage → Advanced DNS**. For the root address, add GitHub Pages’ four `A` records on host `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153` and `185.199.111.153`. For `www`, add a `CNAME` pointing to the GitHub Pages host shown in the repository’s Pages instructions. Remove conflicting parking or forwarding records for those same hosts.
5. After DNS updates, enable **Enforce HTTPS** in GitHub Pages settings.

Keep the domain’s nameservers as they are unless Namecheap or GitHub support tells you otherwise. DNS changes can take time to propagate.
