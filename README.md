# Nataliia Kushnir — website

A responsive, custom-designed static portfolio site for GitHub Pages. It uses Nataliia’s supplied photographs, original illustrations and one short process video. The illustrations have not been edited. No third-party portfolio or stock photographs are used.

## Preview

Open `index.html` in a browser. No build step or paid website builder is required. The hero video may not autoplay in every local preview; browsers commonly restrict autoplay, while the site is served over HTTPS.

## Publish with GitHub Pages

1. The HTML, CSS, JavaScript, `CNAME` and selected media files are all in this repository’s root.
2. In **Settings → Pages**, choose **Deploy from a branch**, select `master` and `/ (root)`, then save. GitHub Pages is already enabled for this repository.
3. The custom domain is `nataliiakushnir.com`. Its `CNAME` file is included.
4. At Namecheap, open **Domain List → Manage → Advanced DNS**. Set the root host `@` to GitHub Pages’ four `A` records: `185.199.108.153`, `185.199.109.153`, `185.199.110.153` and `185.199.111.153`. For `www`, add a `CNAME` pointing to `nataliia-kush.github.io`. Remove only conflicting parking or forwarding records for those same hosts.
5. After DNS updates are recognized by GitHub, enable **Enforce HTTPS** in Pages settings.

Keep the domain’s nameservers as they are unless Namecheap or GitHub support tells you otherwise. DNS changes can take time to propagate.
